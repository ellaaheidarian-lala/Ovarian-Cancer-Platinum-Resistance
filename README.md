# Ovarian Cancer Platinum-Resistance & Clinical Prognosis Platform

An advanced multi-modal clinical decision support system integrating transcriptomic expression signatures, pathological parameters, and clinical symptoms to predict chemotherapy response in ovarian cancer.

## Project Structure
- `app_platinum.py`: Streamlit interactive clinical decision support web application.
- `train_platinum_resistance.py`: Machine learning training pipeline.
- `advanced_platinum_model.pkl`: Serialized classification model.
- `platinum_feature_importance.png`: Feature importance visualization.
